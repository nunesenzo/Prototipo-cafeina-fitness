# TERRA — Protótipo de catálogo

Protótipo estático criado com auxílio do ChatGPT a partir de uma proposta e paleta de cores definidas pelo autor do projeto. Produtos, preços e marca são demonstrativos.

## Abrir o protótipo

Abra `index.html` no navegador. Não é necessário instalar Node.js, npm ou dependências. As fontes do Google Fonts precisam de internet; sem conexão, o navegador usa fontes alternativas.

## Arquivos

- `index.html`: toda a estrutura HTML, os estilos CSS dentro de `<style>` e o JavaScript dentro de `<script>`.
- `ambiente.jpg`: fotografia principal.
- As outras seis imagens `.jpg`: fotografias do catálogo.
- `README.md`: esta documentação.

Mantenha o HTML e as imagens na mesma pasta.

## Funcionalidades

Busca, filtros por categoria, ordenação por preço e prévia de mensagem específica por produto. Os botões abrem uma simulação de atendimento: não há número real de WhatsApp configurado, página individual de produto, carrinho ou pagamento.

## Enviar ao GitHub pelo navegador

1. Extraia o arquivo ZIP.
2. Abra a pasta `prototipo-terra` extraída.
3. No seu repositório, escolha **Add file → Upload files**. Em um repositório vazio, use **uploading an existing file**.
4. Arraste os arquivos de dentro da pasta: `index.html`, as sete imagens e este `README.md`.
5. Clique em **Commit changes**.

Envie os arquivos extraídos, não o ZIP. O `index.html` deve aparecer diretamente na raiz do repositório.

## Sobre esta versão

Este pacote contém somente o protótipo original. Ele usa HTML, CSS e JavaScript puro (vanilla), com CSS e JavaScript embutidos no HTML. Não contém SCSS nem a futura organização em módulos. As fotografias demonstrativas foram obtidas do Unsplash; seus identificadores originais estão registrados em comentários no HTML.
